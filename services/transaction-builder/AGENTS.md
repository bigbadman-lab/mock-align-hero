# Transaction builder rules

- Transaction builder: separate Render service in services/transaction-builder (own pinned deps incl. @pump-fun/pump-sdk loaded via CJS, own HMAC secret, exactly one instance) that only builds unsigned, MAC-bound candidates from official SDK instructions — creation (create_v2+fee config+creator-vault quote ATA+60/25/15) atomic; for $MCP launches the optional first buy is the last instruction of that same transaction (site converts the saved amount exactly, re-checks it before signing; unbuildable buy = refused, never stripped); only the SOL rehearsal uses a separate later buy — simulates read-only and never signs/submits; recipients, 60/25/15 split, quote mint, RPC, programs and ALT are server env only; website reads only its /ready via src/lib/tx-builder/status.server.ts — keeps launch code and keys out of the site and the MCP worker.
- Child creator binding: site route /api/creator/launch-prepare (off unless MCPX_CHILD_LAUNCH_ENABLED=1) runs src/lib/tx-builder/launch-gate.ts — 60% creator = SIWS session wallet signed in ≤10 min ago, connected wallet must match, builder candidate re-inspected before signing; keeper verifyRecipients holds payouts unless chain shares = registered creator/env ops/env platform; builder refuses to start without MCPX_NATIVE_DEPLOYER_PUBLIC_KEY, with conflicting recipients, or with any private-key variable — so neither browser nor config error can redirect child fees.
- Canonical $MCP: mcpx_rw_config.mint is the single source of truth (Treasury, Worker #3 via site state, child keeper); the launch gate (prepare and verify) refuses any builder binding whose quoteMint differs from it, and refuses when it is unset — so a mistyped builder MCPX_QUOTE_MINT can never pair children with another token.
- SOL rehearsal: a request/binding with `rehearsal:"SOL"` builds on Pump's native SOL quote (no parent curve, no quote ATA) only when MCPX_SOL_REHEARSAL_CREATOR is set and equals the creator (quoteScope in service.mjs); every other request keeps the $MCP quote — so the one-time rehearsal can never become a public SOL option.
