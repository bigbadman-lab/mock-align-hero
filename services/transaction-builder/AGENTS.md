# Transaction builder rules

- Transaction builder: separate Render service in services/transaction-builder (own pinned deps incl. @pump-fun/pump-sdk loaded via CJS, own HMAC secret, exactly one instance) that only builds unsigned, MAC-bound candidates from official SDK instructions — creation (create_v2+fee config+60/25/15) atomic, optional buy a separate later transaction gated on on-chain fee verification — simulates read-only and never signs/submits; recipients, 60/25/15 split, quote mint, RPC, programs and ALT are server env only; website reads only its /ready via src/lib/tx-builder/status.server.ts — keeps launch code and keys out of the site and the MCP worker.
